# Site Web - Polygraphie et Dépistage Apnée du Sommeil Marseille

Site web professionnel optimisé pour le référencement naturel (SEO) pour un cabinet médical spécialisé dans le dépistage de l'apnée du sommeil à Marseille.

## 🎯 Objectifs SEO

Ce site a été conçu pour un référencement naturel optimal avec :

### Optimisations techniques SEO
- ✅ **Balises meta** optimisées (title, description, keywords)
- ✅ **Schema.org markup** pour médecin et service local
- ✅ **Open Graph** pour réseaux sociaux
- ✅ **Sitemap.xml** pour indexation Google
- ✅ **Robots.txt** configuré
- ✅ **Structure HTML sémantique** (h1-h6, section, article)
- ✅ **URLs canoniques**
- ✅ **Performance optimisée** (compression, cache)

### Mots-clés ciblés
- Apnée du sommeil Marseille
- Polygraphie ventilatoire Marseille
- Médecin généraliste Marseille
- Dépistage apnée sommeil
- SAOS Marseille
- Syndrome apnées obstructives

### SEO Local (Marseille)
- Balises géographiques (geo.region, geo.placename)
- Schema LocalBusiness avec coordonnées GPS
- Mention de Marseille dans le contenu
- Google Maps intégré

## 🚀 Installation et Configuration

### 1. Personnaliser les informations

Modifiez dans `index.html` :
- **Nom du médecin** : Remplacez "Dr Lacroix" par votre nom
- **Adresse complète** : Section contact
- **Téléphone** : Remplacez "+33XXXXXXXXX" par votre numéro
- **Email** : Remplacez "contact@votre-domaine.fr"
- **Coordonnées GPS** : latitude/longitude dans le Schema.org
- **Horaires d'ouverture** : Adaptez selon votre cabinet
- **URL du domaine** : Remplacez "votre-domaine.fr" partout

### 2. Images à ajouter

Placez vos images dans le dossier `images/` :
- Logo du cabinet
- Photo du cabinet
- Photo du Dr
- Matériel de polygraphie
- Images illustratives

### 3. Google Maps

Dans `index.html`, ligne avec iframe Google Maps :
- Allez sur Google Maps
- Cherchez votre adresse
- Cliquez "Partager" > "Intégrer une carte"
- Remplacez l'URL dans l'iframe

### 4. Configuration serveur

#### Hébergement
Uploadez tous les fichiers sur votre hébergeur via FTP.

#### Certificat SSL
Activez HTTPS (obligatoire pour SEO) :
- Contactez votre hébergeur
- Activez ensuite la redirection HTTPS dans `.htaccess`

#### Domaine
Pointez votre nom de domaine vers l'hébergement.

## 📊 Actions SEO post-installation

### 1. Google Search Console
1. Allez sur [Google Search Console](https://search.google.com/search-console)
2. Ajoutez votre propriété (domaine)
3. Vérifiez la propriété
4. Soumettez le sitemap : `https://votre-domaine.fr/sitemap.xml`

### 2. Google My Business
**ESSENTIEL pour le SEO local !**
1. Créez une fiche [Google My Business](https://www.google.com/business/)
2. Renseignez :
   - Nom du cabinet
   - Adresse complète
   - Téléphone
   - Horaires
   - Photos
   - Catégorie : "Médecin généraliste"
   - Services : "Polygraphie", "Dépistage apnée du sommeil"
3. Demandez des avis patients (très important pour SEO local)

### 3. Google Analytics
1. Créez un compte [Google Analytics](https://analytics.google.com)
2. Ajoutez le code de suivi dans `index.html` avant `</head>`

### 4. Annuaires médicaux
Inscrivez-vous sur :
- Doctolib
- PagesJaunes
- Annuaire de l'Ordre des Médecins
- Annuaires santé locaux

### 5. Contenu régulier
Pour améliorer le SEO :
- Ajoutez un blog avec articles sur l'apnée du sommeil
- Publiez régulièrement (1-2 fois/mois)
- Partagez sur réseaux sociaux
